# Axiom 1 — No Absolute Reference
## اصل ۱: نبود مرجع مطلق

> **Structural Causal Chain:**
> Constraint → Differential Tension (ΔΦ) → Quantized Step (δs) → Cadence → Metric Emergence (g_μν) → Observable Dynamics

**Purpose / هدف:**
Establish the foundational relationality of SDF dynamics.
تثبیت رابطه‌ای‌بودن بنیادی دینامیک SDF.

**Role in Causal Architecture:**
- **Stage:** Foundational Axiom (G-precondition)
- **Function:** Axiom 1: no absolute reference frame exists; all dynamics are relational.
  Every observable is defined relative to the constraint configuration C and the
  differential tension field ΔΦ = ∇Φ − ∇Φ_ref (differential tension of the constraint
  potential Φ), never to an external background.
  Formally, the effective metric carries no external coordinate dependence:

  $$g_{\mu\nu} = g_{\mu\nu}(C, \Delta\Phi, \omega_c) \quad \text{— emergent, not fundamental}$$

  with the cadence operator itself defined relationally:

  $$\omega_c = \frac{1}{\delta\tau}, \qquad \delta s = s_0 \cdot n,\; n \in \mathbb{Z}^+$$

  **Operational consequence:** any quantity that reduces to a function of an
  absolute background (e.g., a bare $H_0$) must be re-expressed through
  boundary-relative observables such as
  $\Delta H_{\text{boundary}}(z) = \kappa_c \cdot \frac{\Delta P_{\text{diff}}(z)}{\rho_{\text{crit}}c^2}\cdot[1-\exp(-z_c/(z+\epsilon))]$.
- **Upstream:** Non-Constraint Foundation (pre-axiomatic)
- **Downstream:** Axiom 2 (constraint priority), G (ground state)
