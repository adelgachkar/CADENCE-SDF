# Axiom 2 — Constraint Precedes Metric

> **Structural Causal Chain:**
> Constraint → Differential Tension (ΔΦ) → Quantized Step (δs) → Cadence → Metric Emergence (g_μν) → Observable Dynamics

**Purpose:**
Fix the ontological priority of constraint fields over geometry.

**Role in Causal Architecture:**
- **Stage:** Foundational Axiom
- **Function:** Axiom 2: constraint fields are prior to any metric structure.
  The metric is a *functional* of the constraint state, not a primitive:

  $$g_{\mu\nu} = g_{\mu\nu}(C, \Delta\Phi, \omega_c)$$

  where $\Delta\Phi$ is the differential tension generated by spatial variation of C,
  and $\omega_c = 1/\delta\tau_n$ is the cadence at which the constraint
  configuration relaxes (the step-propagation speed $v_{\rm step} = \delta s_n/\delta\tau_n$ is dimensionally distinct).
  No term in the functional may reference a pre-existing
  metric; the expansion observable is likewise constraint-derived:

  $$H_{\text{eff}}(z) = H_{\text{metric}}(z) + \Delta H_{\text{boundary}}(z)$$

  with both terms traceable to $C$ via $\Delta P_{\text{diff}} = P_{\text{void}} - P_{\text{filament}}$.
- **Upstream:** Axiom 1 (relationality)
- **Downstream:** Axiom 3 (spatialization), Cid structural constraint
